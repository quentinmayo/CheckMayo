# Developer support

Support CheckMayo's open-source development through [Quentin Mayo's Buy Me a Coffee page](https://buymeacoffee.com/quentinmayo).

The public creator profile was verified through the maintainer's signed-in account. GitHub funding points to this profile. Self-hosted operators can set `CHECKMAYO_DONATION_URL` to their own Buy Me a Coffee profile. Payout administration remains with the creator; no payment or payout transaction is part of platform testing.

Do not put the signup password, verification messages, payout details, or personal financial data in this repository.

Commercial support and additional managed security tooling: https://mayoaspm.com/.
