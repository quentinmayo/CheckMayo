CheckMayo

Privacy and data choices

Updated October 12, 2026.

Community registry

The public CheckMayo registry is operated by Programming Securely. Visitors can browse approved scanner packages without an account. Registered contributors provide an email address and sign-in credentials, workspace membership and the package information they submit. Local passwords are hashed. Session cookies keep you signed in. Administrator-configured OIDC or directory authentication may process identity attributes with the configured provider.

Approved community packages are public; do not submit credentials, private source code or personal data in a package. The registry host disables scan execution and external integrations. Security findings from independent self-hosted controllers are not automatically uploaded to this public registry.

Self-hosted controllers

Your operator controls its database, runners, credentials, reports, findings, policies, memberships and audit history. Encrypted connection credentials and configured providers are used for the integrations you enable. Optional AI summaries are off by default and use the operator’s configured Ollama service. Contact your operator for that instance’s access and retention rules.

Support and technical records

Hosting and security systems process request metadata and operational logs. Support and feature requests use the Programming Securely support service, which stores your submitted text, optional email and page/client details. Authorized administrators can review reports; request titles and references may be included in internal Slack notifications. Do not submit private vulnerability evidence, passwords or API keys through this form.

Access and deletion

Use Support / Feature Request to request access, correction or deletion of registry account or contribution data. Include a contact address so ownership can be verified. Removing an account or package may require review of shared-workspace access and published immutable versions. The current preview does not provide a self-service account-erasure button. We have not published a fixed retention period or a guaranteed backup-erasure time. Clearing browser storage does not delete server records.

Other websites

Linked repositories, donation services and identity providers handle information under their own notices. This page will be updated when the service’s practices change.
